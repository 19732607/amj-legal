# amj-legal

Páginas legales públicas de las aplicaciones **AMJ Técnicos** y **AMJ Empresas** (A.M.J. MAINTENANCE SERVICES CORP. S.L.), exigidas por Google Play y App Store:

- `eliminar-cuenta/` — cómo eliminar la cuenta y los datos
- `privacidad-apps/` — política de privacidad de las aplicaciones

Se publican con GitHub Pages (workflow `pages.yml`). Solo HTML estático; sin código de la app ni claves.
Copia de referencia de los textos: `docs/web/` del repositorio `amj-tecnicos-ios`.
